# 動画の撮影日時エディタ

動画ファイル（MP4 / MOV）の撮影日時を GUI で書き換えるツールです。

編集ソフトで書き出した動画は撮影日時が「書き出した日時」になってしまい、写真アプリや Immich などで並び順がずれます。このツールを使うと、元動画の撮影日時を書き出しファイルにまとめてコピーできます。

中身は [ExifTool](https://exiftool.org/) を呼び出す Python（tkinter）アプリで、1 ファイルだけで動きます。

## できること

変更方法は 4 つあります。どれも書き込む前に「変更後」列で結果を確認できます。

- **元動画に合わせる**：撮影したままの元動画の撮影日時を、書き出したファイルにコピーします
  - 元動画をまとめて選ぶと、ファイル名、または長さ（デュレーション）で自動的に対応付けます
  - 長さが近い元動画が複数ある場合は「要確認」と表示します
  - 元動画の途中から書き出した場合は、書き出し開始位置の分だけ時刻をずらせます
- **日時を指定**：すべてのファイルを同じ日時にします
- **時間をずらす**：カメラの時計のずれなどを、日・時・分・秒単位で補正します
- **ファイル名から**：`VID_20240501_120000.mp4` のような名前から日時を読み取ります

そのほか、次の動作をします。

- タイムゾーンを正しく扱います（iPhone 動画のタイムゾーン付き撮影日時も引き継ぎます）
- 元ファイルを `*_original` としてバックアップできます
- ファイルの更新日時も撮影日時に合わせられます
- 日本語のファイル名に対応しています

## 対応形式

| 用途 | 形式 |
|---|---|
| 書き換えるファイル | MP4, MOV, M4V, 3GP |
| 元動画として読み取れるファイル | 上記に加えて MTS / M2TS（AVCHD）, AVI, MXF |

MXF は、Sony のカメラが作る `C0001M01.XML` が同じフォルダにあれば、そこからタイムゾーン付きの撮影日時を読み取ります。

## インストールと起動

### macOS

```bash
brew install python python-tk exiftool
export PATH="$(brew --prefix python)/libexec/bin:$PATH"   # python コマンドを使えるようにする
python video_date_editor.py
```

`export` の行を `~/.zprofile` に追記しておくと、次回から設定は要りません。

### Windows

1. [Python](https://www.python.org/downloads/) をインストールします
2. [ExifTool](https://exiftool.org/) の Windows 版を展開し、`exiftool.exe` と `exiftool_files` フォルダを `video_date_editor.py` と同じフォルダに置きます
3. `python video_date_editor.py` で起動します

## トラブルシューティング

**macOS でウィンドウが真っ黒になる・表示が崩れる**

描画テーマを切り替えて起動すると直ることがあります。

```bash
VDE_THEME=clam python video_date_editor.py
```

**MXF の変更後の時刻が 9 時間ずれる**

カメラによって日時の記録方法が異なります。「MXF の日時を UTC として扱う」のチェックを切り替えてください。

**自動対応付けで見つからない・取り違える**

長さの許容差（初期値は ±0.5 秒）を調整してください。見つからないときは広げ、取り違えるときは狭めます。

## 注意

- 書き換える前に、大事な動画はバックアップしてください（初期設定では `*_original` が残ります）
- MXF への書き込みはできません（ExifTool が対応していないため）
